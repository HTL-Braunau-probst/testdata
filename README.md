# Inhalt

in diesem Repo können Dateien beliebig heruntergeladen werden. Diese dienen rein zu Testzwecken.

# Links zum herunterladen

alle Dateien können mit dem Link:

`https://raw.githubusercontent.com/HTL-Braunau-probst/testdata/main/` und `[full-path-to-file]` 

heruntergeladen werden.

z.B:

`wget https://raw.githubusercontent.com/HTL-Braunau-probst/testdata/main/htl_logo.jpg`

`curl https://raw.githubusercontent.com/HTL-Braunau-probst/testdata/main/projects/p1/project_1.txt`
